# Creole_Approche_hybride

# Système de traduction automatique pour le créole haïtien

Ce dépôt contient les travaux réalisés dans le cadre de mon mémoire de maîtrise en informatique (intelligence artificielle) à l'Université du Québec à Montréal (UQAM).

L'objectif de ce projet est de développer et d'évaluer des systèmes de traduction automatique pour le créole haïtien, principalement vers l'anglais et le français, à l'aide du modèle multilingue **NLLB-200**. Le projet explore différentes stratégies d'amélioration des performances, notamment l'augmentation de données par **code-switching** ainsi que l'intégration de **corpus culturellement enrichis**.

Le dépôt regroupe les scripts de prétraitement des données, les pipelines d'entraînement, les outils d'évaluation ainsi que les expériences réalisées dans le cadre du **WMT 2026 Creole Machine Translation Shared Task**.
